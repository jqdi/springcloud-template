## 2. Research Findings（代码模式分析）

### F-Controller（system/service 侧）

```
私有 toQueryWrapper(searchFields...)  →  String 字段 .like()；Integer 字段 .eq()
page()  →  PageDTO.of(current, size)，调 service.list(page, queryWrapper)，page.getTotal() 取总数
list()  →  不分页，供 adminapi export 调用
query() →  getById + copyProperties
save()  →  copyProperties + service.save()
update()→  copyProperties + service.updateById()
remove()→  判空 + service.removeBatchByIds(req.getIdList())
```

### F-Feign（system/api 侧）

```
@FeignClient(value=Constants.FEIGNCLIENT_VALUE, path="/{entityLower}", fallbackFactory=ThrowExceptionFallback.class)
page(current, size, ...searchParams)  →  @GetMapping("/page")  PageResp<Resp>
list(...searchParams)                 →  @GetMapping("/list")   List<Resp>
query(Integer id)                     →  @GetMapping("/query")  Resp
save(Req)                             →  @PostMapping("/save")  Boolean
update(Req)                           →  @PostMapping("/update") Boolean
remove(RemoveReq<Integer>)            →  @PostMapping("/remove") Boolean
```

searchParams = 所有非主键、非审计的 String 字段，`required=false`

### F-Req/Resp

- Req：只有业务字段（SysRole 模式：**无**审计字段）
- Resp：全部字段含审计字段（createTime/createBy/updateTime/updateBy）

### F-Enum

```java
public interface ${entity}Enum {
    @AllArgsConstructor @Getter
    enum Status { ENABLE(1,"启用"), DISABLE(0,"停用"); private Integer code; private String desc; }
    // 按业务需要扩展
}
```

### F-adminapi Controller

```
@Validated @RestController @RequestMapping("/{entityLower}")
注入 @Autowired ${entity}Feign ${entityLower}Feign;

page()   →  @RequirePermissions("{module}:{entityLower}:query") @GetMapping("/page")
query()  →  @RequirePermissions("{module}:{entityLower}:query") @GetMapping("/query") @NotNull Integer id
save()   →  @OperationLog(title,INSERT) @RequirePermissions("{module}:{entityLower}:save")  @PostMapping("/save")
update() →  @OperationLog(title,UPDATE) @RequirePermissions("{module}:{entityLower}:update") @PostMapping("/update")
remove() →  @OperationLog(title,DELETE) @RequirePermissions("{module}:{entityLower}:remove") @PostMapping("/remove")
export() →  @OperationLog(title,EXPORT,isSaveResponseData=false) @RequirePermissions("{module}:{entityLower}:export") @GetMapping("/export")
           → feign.list() → copyArrayProperties → ExcelUtil.write2httpResponse
```

### F-Excel（adminapi）

```
@Data
@ExcelProperty(value="列名") 每个字段
@ExcelProperty(value="创建人", converter=SysUserConverter.class)  ← createBy
@ExcelProperty(value="更新人", converter=SysUserConverter.class)  ← updateBy
```
